# Martin Røed Flyum

I build web applications with TypeScript, React and PostgreSQL, and work with the
Linux systems that keep them running.

My projects cover the application itself, the tools around it, and deployment and
recovery. I use AI assistance during development and check the results with API,
browser and operational tests. The project case studies describe what was tested
and where the limits remain.
